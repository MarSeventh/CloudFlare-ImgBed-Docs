# 功能特性

CloudFlare ImgBed 提供了丰富的功能特性，满足不同用户的需求。

## 🚀 核心功能

### 文件上传

- **常见文件支持**：可托管图片、动图、视频、音频及其他常见文件
- **多种上传方式**：
  - 拖拽上传
  - 点击选择上传
  - 粘贴上传（支持文件和 URL）
  - 批量上传
  - 递归文件夹上传，并保留相对目录结构
- **实时进度显示**：上传过程中显示实时进度
- **可选图片优化**：支持上传前压缩图片或转换为 WebP
- **大文件支持**：Telegram、R2、S3 和 Discord 支持分块上传，Hugging Face 支持 LFS 直传
- **失败重试**：可自动切换可用渠道重试上传

### 存储渠道

| 渠道类型 | 大小与配额 | 特点 |
|---------|-----------|------|
| Telegram Bot | 单片 20 MB，较大文件可分片 | 免费易用，支持图片压缩 |
| Cloudflare R2 | 受 Cloudflare 套餐、请求体和对象限制 | 与 Cloudflare 部署集成，支持分块上传 |
| S3 兼容存储 | 取决于服务商 | 可接入多种对象存储，支持自定义 Endpoint 与 CDN |
| Discord | 单片通常为 10 MB，Nitro 通常为 25 MB，较大文件可分片 | 配置简单，适合轻量使用 |
| Hugging Face | 受平台策略限制 | 支持 LFS 大文件直传和私有数据集仓库 |
| WebDAV | 取决于服务商 | 可接入自建或第三方 WebDAV 服务 |

具体限制和费用以所选服务商及部署平台的当前规则为准。

### 文件管理

- **目录功能**：支持创建目录，文件分类管理
- **批量操作**：支持复制、下载、移动、标签、黑白名单和并发删除
- **文件搜索与筛选**：按名称、目录、标签、渠道、文件类型、访问状态等条件查找文件
- **标签管理**：支持标签编辑、批量设置和自动补全
- **详细信息**：查看文件大小、上传时间、来源 IP 等
- **多种视图**：提供卡片和列表视图，并支持框选多选

### 多样化复制

- **原始链接**：直接的文件访问链接
- **Markdown**：`![](图片链接)` 格式
- **HTML**：`<img src="图片链接">` 格式
- **BBCode**：`[img]图片链接[/img]` 格式

### 智能功能

- **设置记忆**：自动保存用户的上传偏好
- **一键复制**：点击链接自动复制到剪贴板
- **错误重试**：失败文件支持重新上传
- **目录建议**：上传页面输入目录支持自动建议和补全

### 文件读取与图片处理

- **统一读取**：通过 `/file/{path}` 读取各存储渠道的文件
- **标准请求能力**：支持 `GET`、`HEAD`，并在对应存储渠道支持 Range 分段读取
- **图片尺寸处理**：可通过 `width`、`height` 与 `fit` 参数缩放、居中裁剪或拉伸图片
- **尺寸控制**：管理员可关闭图片处理或限制客户端允许请求的尺寸组合

## 🌐 国际化

- **中英文双语**：所有页面文本支持中英文动态切换
- **语言记忆**：语言偏好自动保存，下次访问自动恢复
- **组件联动**：Element Plus 组件库语言包随界面语言联动切换

## 🎨 界面特性

### 现代化设计

- **响应式布局**：适配桌面和移动设备
- **深色模式**：支持浅色/深色主题切换
- **统一视觉**：使用扁平、轻量的玻璃质感设计和一致的主题色
- **移动端交互**：支持移动端双列卡片、滑动翻页和紧凑操作布局

### 自定义配置

- **背景设置**：
  - 可关闭壁纸并使用纯色背景
  - 单图背景
  - 多图轮播
  - Bing 随机图
  - 自定义透明度和切换时间
- **品牌定制**：
  - 自定义 Logo 和网站名称
  - 自定义网站标题和图标
  - 自定义页脚链接
- **链接格式**：支持自定义链接前缀

## 🔐 安全功能

### 身份认证

- **密码安全**：PBKDF2 密码哈希存储，兼容已有明文密码自动升级
- **会话管理**：HttpOnly Cookie 会话，管理端和用户端独立隔离
- **会话安全策略**：支持开启 Cookie Secure 模式（仅 HTTPS 传输），支持分别配置会话有效期
- **管理员认证**：后台管理页面密码保护
- **上传认证**：Web 和 API 上传认证码
- **API Token**：支持设置过期时间，过期后自动删除
- **API Token 权限**：可分别授予 `upload`、`delete`、`list` 和 `manage` 权限
- **访问控制**：支持来源域名限制、文件黑白名单和图片处理尺寸限制
- **密码重置**：支持通过环境变量重置认证，忘记密码时可恢复

### 内容安全

- **图片审查**：集成第三方 API 进行内容审查
- **IP 管理**：
  - 上传 IP 记录和统计
  - IP 黑名单与白名单
  - 通过自定义 API 查询并记录 IP 归属地
- **白名单模式**：仅允许白名单图片访问


## 🔧 管理功能

### 文件管理

- **图库浏览**：可视化文件浏览界面，支持卡片视图和列表视图
- **框选多选**：卡片视图支持从空白区域框选多选文件
- **分页加载**：大量文件时的高效加载
- **批量操作**：支持按用户选择顺序进行操作
- **并发批量删除**：单次请求可并发删除多个文件，并返回逐项结果
- **文件移动**：支持文件在目录间移动，目录树可视化选择
- **标签管理**：为文件添加和管理标签，支持自动补全
- **元数据编辑**：支持编辑文件名、文件类型、重命名 File ID
- **备份恢复**：支持批量备份和恢复文件数据
- **索引重建**：支持批量索引重建，规避 CPU 时间限制
- **公开浏览**：可开放指定目录供访客浏览

### 用户管理

- **上传统计**：用户上传文件数量统计
- **IP 追踪**：记录上传者 IP 和地理位置
- **权限控制**：用户上传权限管理

### 系统状态

- **存储统计**：查看文件数量、占用空间和渠道分布
- **上传趋势**：按日期、渠道类型或渠道名称查看上传趋势
- **渠道容量**：支持为 R2、S3 和 WebDAV 渠道配置容量阈值

### 系统设置

- **渠道管理**：多存储渠道配置和切换
- **负载均衡**：多渠道负载均衡设置
- **缓存管理**：自动清理 CDN 缓存
- **公告系统**：站点公告发布功能
- **客户端默认设置**：支持配置默认上传渠道、命名方式、压缩设置等
- **图片处理设置**：支持开关图片尺寸处理并配置允许尺寸

## 🌐 API 支持

### HTTP API

- **完整接口**：提供上传、读取、删除、批量删除、列出、随机图和 Token 管理 API
- **文件读取**：支持二进制响应、HEAD、Range 及可选图片尺寸处理
- **权限控制**：受保护接口可使用带细分权限的 API Token
- **接口文档**：参数与响应说明请参阅 [API 基本介绍](/api/)

### WebDAV 支持
- **标准协议**：支持 `OPTIONS`、`PROPFIND`、`GET`、`PUT`、`DELETE`、`MOVE` 和 `MKCOL`
- **目录浏览**：支持通过 WebDAV 客户端浏览和管理文件
- **文件操作**：支持上传、下载、移动、删除文件和创建目录

### 第三方集成

- **PicGo 支持**：可与 PicGo 图床工具集成
- **跨域支持**：API 支持跨域访问

## 📊 部署与运维

### 多种部署方式

- **Cloudflare Pages**：Git 仓库关联的 Serverless 部署，配置直观，并可通过 URL 使用图片转换
- **Cloudflare Workers**：支持 GitHub Actions 部署及 Cloudflare Images 图片处理
- **Docker**：Node.js 与 Hono 自托管服务，使用 SQLite 和本地数据目录

### 性能优化

- **CDN 加速**：Cloudflare 部署可使用全球 CDN 网络
- **缓存策略**：Worker 根据业务 `Cache-Control` 缓存公开响应，并避免缓存 Range 片段
- **预览优化**：管理端图片使用异步解码和屏外延迟渲染，降低大量预览时的卡顿

### 稳定性

- **故障切换**：上传失败自动切换其他渠道重试
- **大文件分块**：支持大文件分块上传，提高稳定性
